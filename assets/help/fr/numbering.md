# Utilisation
---
## Conversions entre bases
---

L'entrée « Bases » du menu ouvre une vue de conversion entre différentes bases
numériques : il y a un champ pour le décimal, l'hexadécimal, l'octal et le
binaire. Saisissez un nombre dans n'importe lequel : les équivalents
apparaissent dans les autres.

L'entrée « Fractions » du menu ouvre une vue qui liste les équivalents
fractionnaires d'un nombre décimal. Saisissez le nombre et validez : les
fractions sont listées de la plus précise à la moins précise.
