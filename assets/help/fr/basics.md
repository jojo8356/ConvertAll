# Utilisation
---
## Principes de base
---

Saisissez simplement un nom d'unité dans le champ « Unité de départ ». Pendant
la frappe, la liste située sous le champ se filtre pour ne montrer que les
unités correspondantes : les noms d'unités correspondent si leurs mots
commencent par les mots saisis. Terminez le nom (ou l'abréviation) de l'unité,
ou appuyez sur Entrée pour utiliser l'unité surlignée dans la liste. Un clic ou
un appui sur une unité de la liste l'ajoute également au champ de saisie. Vous
pouvez aussi utiliser les flèches haut et bas pour survoler les unités proches
dans la liste.

Répétez la sélection dans le champ « Unité d'arrivée ». Une fois les deux
unités saisies, si elles sont compatibles, les champs numériques du bas
s'activent. Saisissez un nombre dans l'un des deux : l'autre affiche
immédiatement le résultat de la conversion.
