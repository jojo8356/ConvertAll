# Fonctionnalités
---

* Les unités de départ peuvent être saisies (avec auto-complétion) ou choisies
  dans une liste.
* Pendant la saisie, la liste d'unités se filtre automatiquement pour ne
  montrer que les unités dont un mot correspond.
* En général, le nom complet d'une unité ou son abréviation fonctionnent.
* Les unités peuvent être combinées avec les opérateurs « * » et « / ».
* Les unités peuvent être élevées à une puissance (carré, cube, etc.) avec
  l'opérateur « ^ ».
* Les unités du dénominateur peuvent être regroupées entre parenthèses.
* Les unités à échelle non linéaire, comme les températures, sont également
  convertibles.
* Les combinaisons d'unités récentes se choisissent dans un menu.
* Un nombre peut être saisi du côté « départ » comme du côté « arrivée », pour
  convertir dans les deux sens.
* Des expressions mathématiques simples peuvent remplacer les nombres.
* Les réglages contrôlent la présentation des résultats numériques.
* Les données d'unités comprennent plus de 500 unités.
* Les conversions entre bases (décimal, hexadécimal, octal et binaire) se font
  dans une vue dédiée.
* Un nombre décimal peut être converti en fractions dans une vue dédiée.
* Le format du fichier de données rend l'ajout d'unités facile.
